What is CORA?

Replace Chrome OS,
not your Chromebook

CORA is a collection of web-based apps that replace the built-in Chrome OS applications and its app store — running right in your browser using the File System Access API. No Linux VM. No Android support required. Just your Chromebook.

CORA replaces

  • The Chrome OS file manager
  • The Chrome Web Store
  • The built-in terminal
  • Default system utilities

No need for

  • Linux developer mode
  • Android app support
  • Powerwash or OS changes
  • Any installs or extensions
Features

Everything you need

📁
CORA Files
A full-featured file manager. Browse, create, rename, and delete files — with ZIP archive support built in.
⌨
CORA Terminal
WebTerm brings a terminal-like experience to your browser. Run commands against your local filesystem without Linux.
🚀
CORA Launcher
A fullscreen app launcher for all your CORA apps, with a search bar and direct filesystem access.
🛍
CORA Store
Browse and install community-made CORA apps. Apps download and extract directly to your CORA filesystem.
🔒
Private by Design
Everything runs locally in your browser. No data is sent to any server. Your files never leave your device.
🧩
Extensible
CORA is built as a platform. Developers can publish apps to the CORA Store with a simple zip and JSON entry.
Open Source

Built in the open
